# 🕵️ Crime Investigation Game (AI-Based)

## 📌 About the Project
This project is an interactive detective game developed by **Team Bonolota**.  
Players act as investigators to solve complex crime cases through evidence analysis and suspect interrogation.

---

## 🚀 Key Features

- 🔍 **Case Investigation**  
  Receive unique crime stories and identify the culprit.

- 🧩 **Evidence Module**  
  Collect and analyze clues to build your case.

- 🤖 **AI Hint System**  
  Get intelligent assistance when stuck during an investigation.

- 🗣️ **Interrogation System**  
  Question suspects using a dedicated interrogation mechanism.

- 🏆 **Leaderboard**  
  Compete with others and track scores.

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Spring Boot  
- **Database:** MySQL  
- **AI Engine:** Python / Rule-Based AI
